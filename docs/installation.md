# 安装与使用

## Codex

复制整个目录：

```text
skill/china-ad-compliance-review
```

到个人 Skills 目录，并确保安装后的目录名称仍为 `china-ad-compliance-review`。随后在对话中使用：

```text
使用 $china-ad-compliance-review 审核这份广告素材，先告诉我能不能发。
```

## 其他支持系统指令的平台

将 `skill/china-ad-compliance-review/prompts/universal.md` 全文放入系统指令或智能体指令。

如果平台支持联网检索或法规数据库，要求模型在引用前打开官方来源，核对条款号、时效和适用范围。如果不支持，必须保留“未做时效核验”的范围声明。

## 最小自检

输入：

> 海报主标题：“0 元开通，终身免费”；底部小字：“仅免首月基础服务费，次月起 199 元/月”。

预期结果应当：

1. 先给出“不能原样发布”或“修改后可发布”；
2. 指出主标题与小字存在直接矛盾；
3. 将该项列为“必改”，而不是泛泛写“建议谨慎”；
4. 没有联网核验时，明确声明法源时效未核验。
